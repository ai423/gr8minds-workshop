# GR8MINDS · אתר הסדנאות

אתר סטטי עם סליקת קארדקום, פרוס ב-Vercel על `workshops.gr8minds.co.il`.
אין build, אין npm, אין תלויות. התלות החיצונית היחידה בדפדפן היא Google Fonts.

## מבנה

| קובץ | תפקיד |
|---|---|
| `workshops.js` | **מקור האמת היחיד.** כל סדנה מוגדרת כאן פעם אחת |
| `index.html` | עמוד הבחירה. מוסיף לבד כרטיס לכל סדנה שאין לה עדיין |
| `agents/index.html` | סדנת האייג'נטים |
| `apis/index.html` | סדנת ה-API |
| `thanks.html` | עמוד תודה. קורא את פרטי הסדנה מ-`workshops.js` |
| `assets/checkout.js` | מודאל ההרשמה, משותף לכל עמודי הסדנאות |
| `assets/checkout.css` | העיצוב של המודאל |
| `api/checkout.js` | יוצר עסקת LowProfile בקארדקום ומפנה לדף התשלום |
| `api/cardcom-webhook.js` | מקבל הודעת תשלום ומאמת אותה מול השרת |
| `vercel.json` | `cleanUrls`, `trailingSlash`, כותרות אבטחה |

**למה `apis` ולא `api`:** הנתיב `/api` שמור בוורסל לפונקציות שרת. אל תשנו את השם.

## איך מוסיפים סדנה חדשה

שני שלבים. **אין מה לגעת בקוד.**

### 1. להוסיף רשומה ל-`workshops.js`

```js
{
  id: 'workshop-xyz-2026-11-03',        // חייב להיות זהה ל-data-product בעמוד
  slug: 'xyz',                           // שם התיקייה, כלומר הנתיב /xyz
  title: 'שם הסדנה',
  tag: 'תת כותרת קצרה',
  blurb: 'פסקה אחת לכרטיס בעמוד הבחירה.',
  whenCard: 'TUE 03.11 &middot; 10:00-12:00',
  whenLong: 'שלישי, 3 בנובמבר 2026, 10:00 עד 12:00',
  whenShort: 'שלישי 3 בנובמבר, 10:00 עד 12:00, אריה שנקר 1 הרצליה.',
  place: 'אריה שנקר 1, הרצליה',
  price: 590,                            // הסכום שנגבה בפועל
  priceNote: 'לפני מע"מ',
  seats: 12,
  invoiceName: 'שם הסדנה · 3 בנובמבר 2026',   // מה שיופיע בחשבונית
}
```

### 2. להעתיק תיקיית עמוד

```bash
cp -r agents xyz
```

ובקובץ `xyz/index.html` להחליף את המזהה בארבעת הכפתורים:

```bash
sed -i '' 's/workshop-agents-2026-09-07/workshop-xyz-2026-11-03/g' xyz/index.html
```

ואז לערוך את התוכן של העמוד כרגיל: כותרות, תאריכים, טקסטים.

**זהו.** אחרי `git push`:

- הסדנה מופיעה לבד בעמוד הבחירה, והכותרת שם מתעדכנת ל"שלוש סדנאות"
- הכפתורים מחוברים לסליקה עם המחיר הנכון
- עמוד התודה מציג את התאריך והמקום הנכונים
- אין הגבלה על מספר הסדנאות

### מה מחזיק את זה

- **המחיר נקבע בשרת בלבד.** העמוד שולח רק `id`. גם אם מישהו יערוך את
  `data-price` בדפדפן, `api/checkout.js` מתעלם ולוקח את המחיר מ-`workshops.js`.
- **מודאל אחד משותף.** עמוד סדנה צריך רק שתי שורות: `checkout.css` ו-`checkout.js`.
  המודאל מזהה את הסדנה מה-`data-product` של הכפתורים.
- **הכרטיסים הקיימים בעמוד הבחירה לא נגזרים מ-JS.** הם כתובים ב-HTML ונשארים
  שם. הסקריפט רק מוסיף כרטיסים לסדנאות שחסרות, כך שגם אם JS ייכשל, מה שכתוב
  בעמוד עדיין מוצג.

## משתני סביבה

ב-Vercel תחת **Settings → Environment Variables**. אין לשמור ערכים אמיתיים ב-repo.

| משתנה | חובה | ברירת מחדל | הסבר |
|---|---|---|---|
| `CARDCOM_TERMINAL` | כן | — | מספר מסוף |
| `CARDCOM_API_NAME` | כן | — | שם משתמש ל-API |
| `CARDCOM_OPERATION` | לא | `ChargeAndCreateDocument` | או `ChargeOnly` בלי הפקת מסמך |
| `SITE_URL` | מומלץ | הדומיין של הבקשה | `https://workshops.gr8minds.co.il`, בלי לוכסן בסוף |

המחירים **לא** באים ממשתני סביבה אלא מ-`workshops.js`, כדי שסדנה ומחיר יישבו יחד.

עד שמגדירים את שני הראשונים, `/api/checkout` מחזיר `503` והמודאל מציג הודעה
מסודרת. שאר האתר עובד כרגיל.

## הזרימה

1. לחיצה על כפתור פותחת מודאל שאוסף שם, אימייל וטלפון.
2. המודאל שולח `POST /api/checkout` עם מזהה הסדנה.
3. הפונקציה יוצרת עסקת LowProfile בקארדקום ומחזירה את כתובת דף התשלום.
4. הדפדפן עובר לדף המאובטח של קארדקום. פרטי אשראי לא עוברים דרכנו.
5. בהצלחה קארדקום מחזיר ל-`/thanks?w=<slug>` ושולח webhook ל-`/api/cardcom-webhook`,
   שמאמת את העסקה מול `LowProfile/GetLpResult` ולא סומך על גוף ה-webhook.
6. בכישלון חוזרים ל-`/<slug>?payment=failed` והמודאל נפתח עם הודעה.

בלי JavaScript הכפתורים עדיין מובילים לתשלום (`ChargeOnly`, בלי פרטי חשבונית).

## מלאי מקומות

האתר לא סופר מקומות. להגדיר בקארדקום הגבלת כמות לכל מוצר, אחרת הוא ימשיך למכור
אחרי שהסדנה מלאה.
