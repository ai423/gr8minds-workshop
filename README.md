# GR8MINDS · דף נחיתה לסדנת האייג'נטים

דף נחיתה סטטי אחד עם סליקת קארדקום, מיועד לפריסה ב-Vercel.

**האירוע:** סדנת שלושה אייג'נטים (קוקפיט / ראדאר / עוגן) · רביעי 2.9.2026, 10:00–12:00 · אריה שנקר 1, הרצליה · 590 ₪ לפני מע"מ · 12 מקומות.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הנחיתה. כל ה-CSS מוטמע, אין build ואין framework |
| `thanks.html` | עמוד תודה, אליו קארדקום מחזיר אחרי תשלום מוצלח |
| `api/checkout.js` | יוצר עסקת LowProfile בקארדקום ומפנה לדף התשלום שלה |
| `api/cardcom-webhook.js` | מקבל הודעת תשלום מקארדקום ומאמת אותה מול השרת |
| `vercel.json` | כותרות אבטחה, `cleanUrls` |
| `.env.example` | רשימת משתני הסביבה הדרושים |

## איך הסליקה עובדת

ארבעת כפתורי ההרשמה בדף מסומנים ב-`data-checkout` ומצביעים על `/api/checkout`.

1. לחיצה פותחת מודאל שאוסף שם, אימייל וטלפון.
2. המודאל שולח `POST /api/checkout`.
3. הפונקציה קוראת ל-`LowProfile/Create` של קארדקום ומחזירה את כתובת דף התשלום.
4. הדפדפן עובר לדף התשלום המאובטח של קארדקום. פרטי האשראי לא עוברים דרכנו.
5. אחרי תשלום מוצלח קארדקום מחזיר ל-`/thanks.html` ושולח webhook ל-`/api/cardcom-webhook`, שמאמת את העסקה מול `LowProfile/GetLpResult`.

בלי JavaScript הקישור עדיין מוביל לתשלום, פשוט בלי פרטי חשבונית (`ChargeOnly`).

## משתני סביבה

להגדיר ב-Vercel תחת **Settings → Environment Variables**. אין לשמור ערכים אמיתיים ב-repo.

| משתנה | חובה | ברירת מחדל | הסבר |
|---|---|---|---|
| `CARDCOM_TERMINAL` | כן | — | מספר מסוף |
| `CARDCOM_API_NAME` | כן | — | שם משתמש ל-API |
| `WORKSHOP_PRICE_ILS` | לא | `696.20` | הסכום שנגבה בפועל, כולל מע"מ (590 + 18%) |
| `CARDCOM_OPERATION` | לא | `ChargeAndCreateDocument` | או `ChargeOnly` בלי הפקת מסמך |
| `SITE_URL` | מומלץ | הדומיין של הבקשה | הדומיין הסופי, בלי לוכסן בסוף |

עד שמגדירים את שני הראשונים, `/api/checkout` מחזיר `503` והמודאל מציג הודעה מסודרת. שאר הדף עובד כרגיל.

## פריסה

```bash
vercel --prod
```

לדומיין משנה: להוסיף `workshop.gr8minds.co.il` ב-Vercel → Domains, ולהגדיר אצל רשם הדומיין רשומת CNAME אל `cname.vercel-dns.com`.

## פיתוח מקומי

```bash
vercel dev
```
